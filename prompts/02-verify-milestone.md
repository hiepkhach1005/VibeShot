# Verify a VibeShot milestone

Use `$vibeshot-development`.

Verify milestone `<M# and name>` independently against its exit criteria, `docs/PRODUCT_SPEC.md`, and
`docs/TESTING.md`. Inspect the diff first, run focused tests before broad tests, and pay special attention
to permission recovery, capture state teardown, coordinate spaces, mixed display scales, privacy, and
preview/export equivalence. Return PASS or actionable FAIL findings with file/symbol references.
