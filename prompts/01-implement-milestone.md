# Implement one VibeShot milestone

Use `$vibeshot-development`.

Implement milestone `<M# and name>` from `docs/IMPLEMENTATION_PLAN.md`.

Run the repository workflow in `AGENTS.md`: planner creates an implementation-ready plan, implementer
completes only this milestone, and tester verifies its exit criteria. Repair concrete test findings up
to the configured limit. Update `docs/PROGRESS.md` and any source-of-truth document made inaccurate by
the implementation. Do not begin the next milestone.
